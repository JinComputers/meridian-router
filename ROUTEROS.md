# MikroTik RouterOS

Для **hAP ax² с RouterOS 7.25.1 и включённым пакетом container** откройте WinBox → Terminal и вставьте целиком строку из [routeros-import-command.txt](routeros-import-command.txt).

Команда скачивает по HTTPS сжатый ARM64-образ, сверяет его контрольную сумму, проверяет свободное место и импортирует контейнер. Контейнер остаётся остановленным. Ключ не запрашивается, маршруты не меняются. Достаточно одного запуска: тест оставляет архив и созданные объекты. Пришлите строки `M7IMPORT` и вывод состояния контейнера.

Из POSIX-терминала ту же строку выводит `sh m.sh --routeros-import-check`. Для выполнения теста используется терминал RouterOS.

Это проверка импорта. Установка Meridian с проверкой Premium, переключением чёрного и белого режимов и автоматическим откатом пока недоступна.
